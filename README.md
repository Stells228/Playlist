Приложение "Playlist" (Android, Java, SQLite)

Данные хранятся в локальной базе SQLite (Класс DBHelper, таблица tracks: _id, artist, title, year, duration).
Длительность хранится в секундах, на экране показывается в формате мм:сс (класс TimeUtils)
При первом запуске база заполняется 14 стартовыми песнями.

Реализовано:

1. Отображение списка. Все записи из БД выводятся в ListView через SimpleCursorAdapter.
   Для каждой композиции показаны порядковый номер, исполнитель, название, год и длительность)

2. Добавление записей. По кнопке "Добавить" открывается диалоговое окно с полями: исполнитель,
   название, год, длительность. Ввод проверяется (пустые поля, год от 1900, формат времени),
   после сохранения запись добавляется в таблицу и список сразу обновляется.

3. Общие параметры. Над списком выводятся кол-во треков, суммарная длительность (SUM) и саммый длинный трек (ORDER BY duration DESC LIMIT 1)
   Значения считаются ПО ТЕКУЩЕЙ выборке

4. Выыборка по интервалам. По кнопке "Фильтр" открывается окно с полями "от - до" для длительности
   и для года, а также поиск по исполнителю/названию. Условия объединяются через AND, пустые поля не
   учитываются, так что можно задать и просто одну границу. Активный фильтр показывается над списком, его можно сбросить.

5. Сортировка. Выпадающий список: по добавлению, по названию (A -> Я, Я -> А), по исполнителю, по году и по 
   длительности (по возрастанию и убыванию)

6. Удаление. Долгое нажатие на трек удаляет его после подтверждения.

7. Оформление: В этот раз я решила использовать "бумажный" стиль: кремовый фон, красные акценты и рисованные иллюстрации, будто листаешь журнал.
   Это сделано, чтобы сыграть на идеи того, что мы как бы уже начали разговор про музыку, но пока что только узнаём о треках.
   Названия и статистика лежат на блоках с глассморфизмом. Список песен оформлен как страница журнала: крупные тонкие номера 01. 02.
   тонкая линия и подписи.
